## 📌 نبذة عن المشروع (Overview)

مرحباً بك! أنا **زكرياء أبيه (Zakariyae ABBIH)**، مطور برمجيات متكامل (Full-Stack Web Developer). 

هذا المستودع يحتوي على الكود المصدري لمعرض أعمالي الشخصي. تم بناء المنصة باستخدام **Next.js** لتوفير تجربة مستخدم سريعة وعالية الأداء، مع دمج طابع أندلسي مغربي فريد يمزج بين الأصالة والهندسة البرمجية الحديثة، لعرض المشاريع، الأنظمة الإدارية، وتطبيقات الويب المختلفة.

---

## ✨ المميزات الرئيسية (Key Features)

- ⚡ **أداء فائق واستجابة سريعة:** تم بناء الواجهة باستخدام **Next.js App Router** لضمان أفضل سرعة تحميل وأعلى تقييمات الأداء.
- 🎨 **هوية بصرية أندلسية مغربية:** تصميم أنيق وفريد يجمع بين التناسق العصري واللمسات المعمارية الأندلسية.
- 🌐 **دعم تعدد اللغات (i18n):** تبديل سلس ومرن بين اللغتين العربية والإنجليزية عبر `LanguageContext`.
- 📱 **تصميم متجاوب بالكامل (Responsive UI):** متوافق تماماً مع جميع الأجهزة والشاشات باستخدام Bootstrap.
- 📁 **عرض المشاريع ودراسات الحالة:** استعراض متكامل للمشاريع السابقة (مثل BlogApi، EcommerceApi) مع توضيح التقنيات المستعملة.
- 📬 **نموذج تواصل تفاعلي:** إمكانية إرسال الرسائل مباشرة مع التحقق التلقائي من البيانات (Form Validation).
